# Email Template Brief — Confirm Signup & Password Reset

**Priority:** High — needed for Supabase auth emails  
**Design reference:** Use the exact same design system as the existing order confirmation email (header, colors, gradients, card styles, footer)

---

## Context

We have Supabase set up with custom SMTP sending through Zoho. We need two more email templates built in the same visual style as the order confirmation email. These will be pasted directly into the Supabase dashboard under Authentication → Email Templates.

**Critical Supabase requirements:**
- The template variable for the action link is `{{ .ConfirmationURL }}` — use this exactly (with spaces inside the braces)
- Templates must be minified (single line, no extra whitespace) to stay under Supabase's 50,000 character limit
- No `{{FIRST_NAME}}` or other custom variables — Supabase auth templates don't support them

---

## Template 1: Confirm Signup

**Use when:** A new user signs up with email/password and needs to verify their email

### Header Section
- Logo: same as order email
- "PREMIUM RESEARCH COMPOUNDS" tagline with rainbow underline: same as order email
- Eyebrow label: `ACCOUNT VERIFICATION` (use the same outlined pill/badge style as "ORDER CONFIRMED")
- Headline: `Almost There.` (same serif style as "You're All Set.")

### Body Section
- Body text: "You just created an account on **Revive Research** — a platform built for researchers who demand transparency, verified quality, and precision. Confirm your email below to unlock full access."

### Green Confirmation Box
Same style as the order email's green "OK / Thank you" box:
- Checkmark circle icon
- Text: `One step away.`
- Subtext: "Every compound ships with a third-party Certificate of Analysis, and our platform gives you tools no other vendor offers."

### Features Box
Same gradient card style as the invite email's "What You Get" section:
- Section label: `WHAT YOU'RE UNLOCKING`
- Row 1: **COA-Verified** (neon green) — compounds with full batch documentation and QR traceability
- Row 2: **Synergy Engine** (cyan) — build research stacks with real-time interaction scoring
- Row 3: **Research Academy** (neon green) — structured compound education with progress tracking
- Row 4: **Pricing Transparency** (cyan) — see exactly how we compare to every major vendor

### CTA Button
- Text: `Verify Email`
- Style: same neon green button as order email / invite email

### Footer
- Same red "RESEARCH USE ONLY" disclaimer box
- Same footer with support email, company name, address, copyright
- Permission text: "You received this email because you created an account at reviveresearch.co"

## Template 2: Password Reset

**Use when:** A user requests a password reset

This email should be shorter and more focused — no features box needed.

### Header Section
- Logo: same as order email
- "PREMIUM RESEARCH COMPOUNDS" tagline with rainbow underline: same as order email
- Eyebrow label: `ACCOUNT SECURITY` (same outlined pill/badge style)
- Headline: `Reset Your Password.`

### Body Section
- Body text: "We received a request to reset your **Revive Research** account password. Click the button below to choose a new one."
- Secondary text: "This link expires in 24 hours. If you didn't request this, no action is needed — your account is secure."

### CTA Button
- Text: `Reset Password`
- Style: same neon green button

### Security Notice
Instead of the green confirmation box, use a neutral/blue-tinted info box:
- Icon: lock or shield symbol
- Text: `Your account is protected.`
- Subtext: "If you didn't request a password reset, someone may have entered your email by mistake. Your password has not been changed."

### Footer
- Same red "RESEARCH USE ONLY" disclaimer box
- Same footer with support email, company name, address, copyright
- Permission text: "You received this email because a password reset was requested for your account at reviveresearch.co"

5. Deliver as two files: `confirm-signup-template.html` and `reset-password-template.html`
