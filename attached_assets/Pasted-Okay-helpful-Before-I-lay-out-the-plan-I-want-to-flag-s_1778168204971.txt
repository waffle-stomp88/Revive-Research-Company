**One important thing to flag first:**

"Subscribe & save on individual products" with PayPal subscriptions has a real architectural problem you should be aware of: **PayPal subscriptions require a pre-created billing plan for each price point.** If you have 137 SKUs across multiple dosage tiers and bulk packs, and each can be subscribed to at a discounted recurring rate, you potentially need hundreds of subscription plans created in PayPal — one per (SKU × subscription tier × discount) combo. PayPal supports this but it's painful to manage.

Some platforms work around this with Stripe (which lets you set arbitrary recurring amounts without pre-defined plans). PayPal is stricter. **Worth knowing before we dive in** — I'm not saying don't do it, just flagging the operational reality. We'll see how your code is currently approaching it.
